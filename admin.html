    站点信息
    POST 查询接口
    启用 POST 接口
    关闭后POST接口将不可用
    留空则不校验口令，任何人可直接调用。
    POST/api/api.php?sn=AAAA-BBBB-CCCC&token=口令
    参数说明  sn 通过 URL Query 传递，token 与启用口令时必填
    成功 200  { "id": 1, "sn": "MOB-20260410-DEMO", "product_name": "...", "product_model": "...", ... }（不含图片字段）
    失败 200  { "valid": false, "error": "序列号不存在或非正品" }
    浏览器调用示例 
    // JavaScript fetch 调用
fetch('https://你的域名/api/api.php?sn=MOB-20260410-DEMO&token=口令', {
  method: 'POST',
  headers: { 'Cache-Control': 'no-cache' }
})
.then(r => r.json())
.then(data => console.log(data));
    工厂模式（数据接收接口）
    启用工厂模式
    关闭后工厂接口将不可用
    留空则不校验口令，任何人可直接调用。
    POST/api/factory_api.php?token=口令
    Content-Type  application/json
    请求体（所有字段） 
    {
  "sn": "MOB-20260502-0001",
  "product_type": "手机",
  "product_name": "旗舰手机 14 Pro",
  "product_model": "M2104K10AC",
  "sn_code": "ABC1234567890",
  "sales_channel": "天猫",
  "manual_link": "https://example.com/manual.pdf",
  "image": "uploads/demo.jpg",
  "remarks": "备注信息"
}
    成功 200  { "success": true, "sn": "MOB-20260502-0001", "message": "产品已保存" }
    失败 200  { "success": false, "error": "缺少必填字段" }
    浏览器调用示例 
    // JavaScript fetch 调用
fetch('https://你的域名/api/factory_api.php?token=口令', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    sn: 'MOB-20260502-0001',
    product_type: '手机',
    product_name: '旗舰手机 14 Pro',
    product_model: 'M2104K10AC'
  })
})
.then(r => r.json())
.then(data => console.log(data));
